# Budget Transparency Dashboard

A dashboard that makes government budget data understandable to any citizen.
Budget data (department, scheme, allocated amount, spent amount, fiscal year)
is loaded into SQLite and explored through an interactive dashboard.

- **Frontend:** React (Vite) + Recharts + Tailwind CSS
- **Backend:** Python Flask REST API (CORS enabled)
- **Database:** SQLite — no external DB setup, runs out of the box
- **LLM:** Google Gemini (`gemini-2.5-flash`) via the `google-generativeai` SDK,
  with a deterministic offline fallback when `GEMINI_API_KEY` is missing, and
  retry logic for 429 rate-limit errors

> The LLM **never runs SQL**. It only turns your question into a structured JSON
> intent (metric, department, year, comparison). The backend translates that
> whitelisted intent into safe, parameterized SQL queries.

## Features

1. **Overview** — total allocated vs spent for a selected year, top departments
   by allocation, allocated vs spent per department, year-over-year trend,
   a year selector that updates every chart, plus a **Download PDF** button
   (html2canvas + jsPDF).
2. **Department drill-down** — click a department to see its schemes in a table
   with allocated, spent and percent utilized.
3. **Comparison view** — compare two fiscal years or two departments side by side.
4. **Ask the Budget** — type (or say, via the Web Speech API) a plain-language
   question. The backend builds a schema summary, asks Gemini for a structured
   JSON intent, and Python translates it into safe parameterized SQL. Returns a
   plain-language answer plus the numbers for a small chart. Graceful fallback
   if voice input is unsupported or the API key is missing.
5. **Red-flag detection** — departments with year-over-year increases over 100%
   and departments with utilization under 40% are shown as “worth a look” cards.
6. **Plain-language insights** — a one-line “what this means” summary per
   department, generated by Gemini with a deterministic template fallback.
7. **Biggest Movers** — top 3 increases and top 3 decreases in allocation
   year-over-year.

## Run it (fresh machine, under 5 minutes)

You need **Python 3.9+** and **Node.js 18+** installed.

### 1. Backend

```bash
cd backend
python -m venv venv

# Windows
venv\Scripts\activate
# macOS / Linux
# source venv/bin/activate

pip install -r requirements.txt
python app.py
```

The API starts at http://localhost:5000. The SQLite database (`budget.db`) is
auto-created and seeded on first start — no manual step needed. To reseed:
`python seed.py --force`.

### 2. Frontend (in a second terminal)

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173 — Vite proxies `/api` calls to the backend.

### 3. Optional: enable Gemini

The app works fully without a key (deterministic offline mode — the header
shows “Offline AI mode”). To get live Gemini answers and insights, set the key:

**Windows (PowerShell):**

```powershell
$env:GEMINI_API_KEY = "your_key_here"
```

**Windows (cmd):**

```cmd
set GEMINI_API_KEY=your_key_here
```

**macOS / Linux:**

```bash
export GEMINI_API_KEY="your_key_here"
```

Alternatively copy `.env.example` to `backend/.env` and paste your key there —
the backend loads it automatically.

## API endpoints

| Method | Path | Description |
| --- | --- | --- |
| GET | `/api/health` | Status + whether Gemini is live or mock |
| GET | `/api/years` | Available fiscal years |
| GET | `/api/departments` | Department list |
| GET | `/api/overview?year=2025-26` | Totals, per-department rows, trend |
| GET | `/api/department?name=Health&year=2025-26` | One department + its schemes |
| GET | `/api/compare?type=year&a=2024-25&b=2025-26` | Year comparison |
| GET | `/api/compare?type=department&a=Health&b=Education&year=2025-26` | Department comparison |
| POST | `/api/ask` | `{"question": "…"}` → JSON intent → safe SQL → answer |
| GET | `/api/red-flags` | Spikes >100% YoY, utilization <40% |
| GET | `/api/movers` | Top 3 increases and decreases YoY |
| GET | `/api/insights?year=2025-26` | One-line “what this means” per department |

## Notes

- All amounts are ₹ crore (1 crore = 10,000,000). The data is realistic-looking
  **sample data** — not official figures.
- Deliberate anomalies are seeded so you can see red flags immediately
  (Police and Transport budget spikes in 2024-25, IT spike in 2025-26,
  Rural Development and Transport utilization around 39%).
